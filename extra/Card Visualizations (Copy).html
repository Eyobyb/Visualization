Nine ways a card can show its answer.

Every Proactive Intelligence card shows one answer Adaly found for you. The frontend owns these nine components; the backend picks one and sends the data, never chart code. Edit any card's JSON below to see how it renders, trims and steps down.

Selection rules

The backend works down this order and stops at the first match. Pick what the card says to see which component it gets.

  1. Reuse the answer's own chart when it shows the card's metric over the card's dimension. Copy its values unchanged.
  2. Otherwise match the card's point to a component, using the list on the left.
  3. Combine rows only when comparable: same metric, source, account and currency.
  4. No fit: a text-only card. Never generated chart code.
